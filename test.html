霧前禪夢，見字如初

「文字如泉，靜謐而流。在喧囂的網路世界中，為心靈保留一方專注閱讀的淨土。」

一、 設計理念

現代網頁長文閱讀中，傳統滑鼠滾輪滾動容易使視線迷失。瀏覽器原生的游標瀏覽功能（F7）僅提供細微的閃爍垂直直線，缺乏段落吸附與物理動態回饋。

Muzen Cursor（霧前游標）承襲 Gruvbox 高對比配色與 Vim 經典按鍵動力學，將文字行/字元級別的視線錨點帶入任意網頁中。透過純鍵盤控制，手部無需離開鍵盤，即可享受極致流暢的沉浸式閱讀體驗。

二、 技術核心突破

為了達到最高相容性與零執行期負擔，我們捨棄了龐大的前端框架執行期，全面採用 Vanilla TypeScript 配合原生 Web Components (Shadow DOM)。

每個字元的螢幕座標皆透過 DOM Range 與 TreeWalker 精確度量，並透過 GPU 硬體加速（CSS translate3d）實現 120fps 的平滑吸附與阻尼動畫。

三、 操作體驗驗證

請嘗試直接點選這一行文字，或是使用鍵盤快捷鍵進行測試：

  • 水平移動：使用 h 向左一個字元，使用 l 向右一個字元。
  • 垂直跨行：使用 j 移動至下一行，使用 k 移動至上一行。
  • 模式切換：按下 v 進入 VISUAL 模式（狀態列與游標將切換為金黃色高對比主題）。
  • 凍結/喚醒：按下 alt + v 可隨時啟動或關閉指標。

使用 Rebase 或 filter-branch 指令來整理

如果 Commit 的數量小，使用 Rebase 應該就足以進行編輯、重整。在「【狀況題】不小心把帳號密碼放在 Git 裡了，想把它刪掉…」章節也曾介紹過 filter-branch 指令，它可以大範圍的對每個 Commit 執行某個指令，並於修改完成後會自動再重新 Commit。所以如果是要把檔案從 Git 裡拔掉，用 filter-branch 指令應該是相對較方便的。

舉例來說，目前的 Commit 紀錄是這樣：

我想要把所有 Commit 的 config/database.yml 這個檔案刪掉：

$ git filter-branch --tree-filter "rm -f config/database.yml"
Rewrite 27f6ed6da50dbee5adbb68102266a91dc097ad3f (7/7) (0 seconds passed, remaining 0 predicted)
Ref 'refs/heads/master' was rewritten

這樣看起來好像刪掉了...假的，其實那些東西都還在，隨時都可以取消剛剛這個指令，把剛剛被刪的檔案救回來：

$ git reset refs/original/refs/heads/master --hard
HEAD is now at 27f6ed6 add dog 2

全部斷乾淨！
